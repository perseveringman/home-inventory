# 2026-05-31

## 物品图与标签视图三连改造

### 1) 编辑物品被覆盖成默认贴纸图 → 修复
- ItemDialog 增加 `imageDirty` 状态：仅在用户真的换图/拍照/AI 配图/移除时才标记。
- 保存逻辑：`imageDirty` 时才使用当前 blob，否则保留 `item.image`，新建空图直接 `undefined`，不再调用 `generateItemThumb` 强制写入。
- CabinetDialog 内的快速添加同步移除强制生成默认图。

### 2) 默认贴纸图太丑 → 替换为语义图
- 新增 `packages/core/src/utils/semantic.ts`：`inferItemSemantic(name, tags, existingEmoji)` 本地启发式 + `generateSemanticThumb(emoji, name, hue)` Canvas 合成。
- 新增 `packages/core/src/services/itemEmoji.ts`：`suggestItemSemantic` 走 DeepSeek → OpenRouter（纯文本，无 vision 配额开销），失败回退本地。
- 新增 `packages/web/src/components/ItemThumb.tsx`：纯 DOM 渲染语义图（emoji + 渐变背景 + 名称），有图就走 BlobImage，无图就语义图，0 字节存储。
- ItemDialog 增加"AI 配图"按钮，一键给无图物品自动生成语义缩略图存为 PNG blob。
- 全站替换：ItemsPage / InboxPage / OverviewPage / LooseListDialog / SearchPage / PhotoDetailPage / CabinetDialog 都切到 ItemThumb。

### 3) 标签固定视图（如旅行必备清单）→ 新功能
- 新增 `packages/core/src/services/tagViews.ts`：TagView 模型，存到 storage `config` store（key=`tagViews`），不破坏 IndexedDB 升级。
- 支持 `mode: 'all' | 'any'`、关键词筛选、是否含待归位、排序、emoji 封面、备注；首次进入种子一个"旅行必备清单"。
- 新增 `packages/web/src/pages/TagViewsPage.tsx`：列表 + 详情双态。`/tags` 列出所有视图，`/tags/:id` 进入单视图（按 room/cabinet 分组的物品网格）。
- 路由注册 + Scenebar 加入"视图"入口。

### 关键约束
- 直接生成 PNG blob 入库的好处：iOS WebView、SSR 环境都能不依赖 Canvas 显示；ItemThumb 的纯 DOM 渲染则在编辑表单/列表里零成本回退。
- TagView 数据存 config store 而不是新增 store，避免触发 IndexedDB 版本升级 → 不影响已有用户。
